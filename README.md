## 📌 Lab Highlights

### 1. Data Structures & Algorithms

The DSA lab progresses from arrays, sorting, and searching to object-oriented programming and recursion.

- **Algorithms:** Bubble sort, selection sort, linear search, and binary search
- **OOP:** Classes, objects, constructors, inheritance, and method overriding
- **Recursion:** Numeric problems, arrays, Fibonacci, subsets, and arrangements

Solutions and expected console output are provided in each task folder.

### 2. Database Management Systems

The SQL lab covers relational data manipulation and commonly used query features.

- **Fundamentals:** Tables, inserts, updates, deletes, filtering, and sorting
- **Queries:** Aggregates, grouping, joins, subqueries, `UNION`, and `INTERSECT`
- **Database objects:** Views and indexes

Each assignment contains an SQL script and a sample result transcript. Assignment 13 uses `INTERSECT`, which requires MySQL 8.0.31 or later.

### 3. HTML & CSS Development

The web development lab builds from basic HTML documents to styled, responsive layouts.

- **HTML:** Links, images, lists, forms, tables, and semantic structure
- **CSS:** Selectors, variables, the box model, Flexbox, and Grid
- **Responsive design:** Media queries and responsive images
- **Practice materials:** Git command transcripts and browser screenshots

Open an assignment's HTML page in a browser to view it.

## 🚀 Quick Start

### Run a Java task

```powershell
cd DSA_Lab_Programs_5th_Sem\Assignment_01_Reading_Array_Values\Task_1
javac Main.java
java Main
```

Compare the result with the task's `output.txt`.

### Run an SQL assignment

From the repository root, run an assignment script with MySQL:

```powershell
mysql -u root -p < DBMS_SQL_Lab_5th_Sem/Assignment_1/assignment1.sql
```

### View an HTML practical

Open any `.html` file under `HTML-CSS-Practicals_5th_Sem` in your browser. Keep the task's related CSS and image files in place.
