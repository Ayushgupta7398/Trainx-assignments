# HTML & CSS Development Lab (BCS554)

The folders `Assignment_01_...` through `Assignment_15_...` follow the lab brief. Each assignment is divided into `Task_1`, `Task_2`, and `Task_3`; files use the descriptive names requested in the brief. Git exercise terminal transcripts are supplied as text files. Each practical HTML page has a `screenshot.png` captured in a browser. Images used by the image exercises are in `images/`.

Open the HTML files directly in a browser. A stylesheet is included alongside the task page when the assignment calls for one.
