# Applied Data Structures and Algorithms Lab (BCS553)

Java solutions for the 15 assignments in the lab brief. Each task has its own folder containing `Main.java` and its expected console output in `output.txt`.

## Assignments

1. Reading Array Values
2. Largest, Smallest and Count
3. Bubble Sort
4. Selection Sort
5. Linear Search
6. Binary Search on a Sorted Array
7. Practice Set
8. Classes and Objects
9. Constructors
10. Parent and Child Classes
11. Method Overriding
12. Recursive Factorial, Sum and Power
13. Recursion on Arrays
14. Sorted Check, Search and Fibonacci
15. Subsets and Arrangements

## Run a task

Open a task folder and run:

```powershell
javac Main.java
java Main
```

Compare the console output with the task's `output.txt`.
